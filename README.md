# Прогнозирование нагрузки и автоматическое управление гибкими электроприёмниками частного жилого дома

Исходный код и данные к статье «Прогнозирование нагрузки и автоматическое управление гибкими
электроприёмниками частного жилого дома при тарифе, дифференцированном по зонам суток»
(XIII Международная научно-практическая заочная конференция «ЭТАП-2026»).

Рассматривается частный дом с электромобилем, бойлером и полным набором бытовой техники
(сценарий C). Почасовое потребление дома моделируется на 2025 г. по реальной температуре воздуха
в Минске, негибкая нагрузка прогнозируется на сутки вперёд моделями машинного обучения, а гибкие
приборы (зарядка электромобиля, нагрев воды, стирка с сушкой, мойка посуды) планируются по
прогнозу и трёхзонному тарифу Республики Беларусь.

## Файлы

| Файл | Что делает | Результат |
|---|---|---|
| `house_c.py` | модель дома: почасовая негибкая нагрузка и гибкие задания (момент появления, крайний срок, энергия, мощность) | `house_c_hourly.csv`, `house_c_jobs.csv` |
| `forecast_c.py` | прогноз негибкой нагрузки на сутки вперёд: наивный, линейная регрессия, случайный лес, градиентный бустинг (scikit-learn); обучение 08.01–31.10.2025, проверка 01.11–31.12.2025 | `model_metrics.csv` (табл. 1 статьи), `forecast_test.csv` |
| `control_c.py` | алгоритм управления гибкими приборами по прогнозу и тарифу, сравнение с работой без управления и с таймером на 23:00 | `control_results.csv` (табл. 2 статьи), `control_profiles.csv` |
| `figures_pub2.py` | рисунки | `fig2_forecast.jpg` (рис. 1 статьи), `fig3_profile.jpg` (рис. 2 статьи), `fig1_system.jpg` (структурная схема, в статью не вошла) |
| `minsk_weather_2025_nasa.json` | почасовая температура воздуха в Минске (53,9° с. ш., 27,57° в. д.), 2025 г., NASA POWER Hourly API, параметр T2M, время UTC | исходные данные |

Все CSV и рисунки в репозитории получены этими скриптами, их можно пересобрать.

## Запуск

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
python house_c.py
python forecast_c.py
python control_c.py
python figures_pub2.py
```

Скрипты запускаются из папки репозитория по порядку: каждый следующий читает CSV предыдущего.
Генератор случайных чисел зафиксирован, поэтому результаты совпадают с приведёнными в статье
(проверено с numpy 2.2.6, pandas 2.3.3, scikit-learn 1.7.2, matplotlib 3.10.9). Расчёт занимает
около минуты. Для рисунков нужен шрифт Times New Roman.

## Основные допущения

- Дом около 150 м², семья из трёх человек, газовое отопление, электроплита.
- Тариф с 1 марта 2026 г. для дома с электроплитой: ночь (23–6 ч) 0,1549 BYN/кВт·ч, пик (17–23 ч)
  0,4646 BYN/кВт·ч, остальное время 0,1807 BYN/кВт·ч; в выходные и праздники весь день действует
  ночная ставка.
- План на следующие 24 ч составляется в 17 ч; температура берётся фактическая (идеальный метеопрогноз).
- Предел нагрузки дома 7 кВт; весовые коэффициенты целевой функции μ = ν = 0,012 BYN/(кВт·ч)².

График нагрузки синтетический: он смоделирован по типовому распорядку семьи и паспортным мощностям
приборов, так как открытых измерений по таким домам нет.
